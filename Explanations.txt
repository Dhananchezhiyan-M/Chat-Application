# Register Page:
Exactly similar to the login page, we are sending the username and password to the backend.

#Home Page:
Have buttons, that used to go to the Login and Register pages.

#App.js:
Here initially the home page opens. So useState("home").
By clicking the buttons useState changes, if register: useState make setPage = "register"

BackEnd:
#authController.js:
Receiving username and password.And check for already the same user name exists.
If new user stores the username and bcrypt password.
await newUser.save();-> Saves in mongodb.
User is used here

In login part we are comparing and correct sending Login successful message.

#authRoutes:
The post request is received here as here is the router is used.
Like http://localhost:3000/auth/api/(adds register or login):
if register: http://localhost:3000/api/auth/register->calls the function in the authController.js
And using User.js in module convert into json for mongodb and is stored in the database.

# Server.js:
In server.js, it used dotenv.config() for using env link to send to the mongodb.
